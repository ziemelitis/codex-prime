# codex-prime

Premier dépôt GitHub préparé pour être publié avec GitHub Pages.

## Contenu

- `index.html` : page d’accueil du site
- `README.md` : documentation du projet

## Publication avec GitHub Pages

Le site est prêt à être publié depuis la branche `main`.

Dans GitHub :
1. Ouvrir **Settings** du dépôt.
2. Aller dans **Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Sélectionner la branche **main** et le dossier **/(root)**.
5. Cliquer sur **Save**.

Une fois GitHub Pages activé, l’adresse sera normalement :

`https://ziemelitis.github.io/codex-prime/`

## Développement

La page utilise uniquement HTML et CSS, sans dépendance ni installation nécessaire. Il suffit d’ouvrir `index.html` dans un navigateur pour la tester localement.

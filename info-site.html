Présentation

Codex Prime est un site de Sandra Ziemele. Il propose une sélection de ressources pour découvrir des outils liés au développement web et au prototypage.

Le site repose sur des pages HTML statiques, des styles CSS et, pour le catalogue, du JavaScript exécuté dans le navigateur. Les liens vers des outils externes ouvrent les sites des fournisseurs concernés.

codex prime. Explorer les outils

Aide

Codex Prime propose une sélection d’outils pour découvrir, créer, tester et publier des projets web.

Utiliser le catalogue

  1. Ouvrez la page Outils.
  2. Saisissez un mot dans le champ de recherche pour filtrer les outils par nom ou description.
  3. Utilisez les boutons de catégories pour préciser votre recherche. Le bouton « Tous » réinitialise le filtre de catégorie.
  4. Suivez le lien « Découvrir » d’un outil pour consulter son site.

Si aucun résultat n’apparaît, effacez votre recherche ou choisissez une autre catégorie.

Signaler un problème
